# 高美館 · 建築漫遊

以 Blender 建立高雄市立美術館主館與周圍園區的照片參考模型，並以 Three.js 顯示於單一 HTML。

## 開啟

- 直接以現代瀏覽器開啟 `高美館建築漫遊.html`，不需安裝套件或連上網路。需支援 WebGL／硬體加速。
- `KMFA.blend`：可編輯 Blender 原始檔。模型位於 `KMFA · Museum in the Park` 場景，原先的預設場景保留。
- `dist/assets/kmfa.glb`：可匯入其他 3D 軟體的模型。
- 網頁提供鳥瞰、廣場、湖畔、俯視，光照、曝光、白模、植栽／人物顯示、自動環繞及 PNG／GLB 下載。

拖曳旋轉、滾輪縮放、右鍵平移；觸控可單指旋轉、雙指縮放。聚焦畫布後 Home 還原鳥瞰，+／− 縮放。手機可用右上角「場景設定」展開控制面板。

## 重建

1. 在 Blender 執行 `scripts/model.py`（每次建立一個新場景）。使用 `__file__` 決定輸出目錄，因此可用 `blender --background --python scripts/model.py`。
2. `npm ci`
3. `npm run build` 重新嵌入模型與程式，輸出 `dist/index.html` 及離線 HTML。
4. `npm start` 提供 http://127.0.0.1:4173 本機預覽。

Three.js 0.180.0 / esbuild 0.25.10。依賴版本鎖定於 package-lock.json。輸出 HTML 不依赖 CDN。

## 準確度

這是建築外觀與園區氛圍的近似模型，不是測繪成果，也不是館方官方模型。依空拍照片重建建築量體、斜面採光頂、半圓迴廊、館前廣場及湖岸的關係。尺寸、園區範圍、植栽、人物與雕塑為示意。模型不包含室內展品、不代表即時施工現況；沒有將外觀改造競圖提案當作落成建物。

參考資料與設計決策見 DESIGN.md，亦可由網頁「關於模型」開啟館方與高雄旅遊網來源。參考照片僅用於研究，未包含於交付檔。
