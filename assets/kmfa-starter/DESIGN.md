# 高美館 · 建築漫遊

Visual thesis: A carefully lit architectural scale model, terracotta and deep green against a pale blue-grey ground, with a restrained dark museum-editor interface.

Content: Full-screen interactive Blender model first; compact identity at upper left; scene controls at right; view presets below; a reference drawer with factual sources and approximation notes.

Interaction: Smooth camera travel between three architectural viewpoints and a plan view; daylight and material studies; optional slow orbit with reduced-motion support.

The existing Blender scene is preserved. A new KMFA scene is created, exported as GLB, and saved in a separate .blend file. All dimensions are visual estimates, not surveyed measurements. Trees and sculptures are representative, not an inventory of actual works. The unbuilt facade competition scheme is not used as built-condition evidence.
